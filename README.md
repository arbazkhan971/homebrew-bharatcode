# BharatCode Homebrew tap

```sh
brew install arbazkhan971/bharatcode/bharatcode
```

- **Linux (x86_64):** installs the prebuilt binary from the GitHub release.
- **macOS:** builds from source (Apache-2.0), requires the Homebrew `rust` toolchain.

[BharatCode](https://github.com/arbazkhan971/bharatcode-cli) is an Indian, local-first,
Apache-2.0 Rust terminal AI coding agent (a fork of Goose with components ported from Codex).
